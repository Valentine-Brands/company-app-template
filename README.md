# Company App Template

A public, stack-neutral starting point for applications created with the [`company-skills`](https://github.com/Valentine-Brands/company-skills) plugin.

The repository contains project rules but no framework boilerplate. The creating agent selects a stack only after it understands the application requirements.

## Preferred use

Install `company-skills` in Claude Code or Codex, then ask:

> Create a company application for [describe the business need].

The `create-company-app` skill copies this starter into a fresh local Git repository and guides the remaining setup.

## Manual use

Clone the repository, remove its existing Git history, initialize a new repository, and replace this README with documentation for the resulting application.
